Research software and data projects

Skill Extraction from Real-World Job Advertisements

Methods: Extreme multi-label classification (XMLC), contrastive learning, ESCO ontology matching, BERT-based semantic retrieval.

I designed and implemented a pipeline for extracting skills from real-world job advertisements. The project uses LLM-assisted data construction, ESCO-standardized skill taxonomies, and contrastive learning to train skill-extraction models for large-scale labor-market research.

GitHub repository · Technical report

Compressed Representations and Attentional Competition in Average Estimation

Methods: Computational cognitive modeling, selective integration, model comparison, Bayesian estimation.

This project studies how people dynamically integrate numeric information in decision-from-experience tasks. It compares selective-integration models with compressed mental-number-line accounts using behavioral experiments and model-based estimation.

Project materials on OSF

Task-specific Strategies in Numeric Magnitude Judgment

Methods: JAGS, MCMC sampling, Bayesian hierarchical modeling, lab.js.

This project studies how task-specific strategies can affect observed numeric magnitude judgments. It uses experiments with multiple average-estimation strategies and Bayesian hierarchical models to identify heterogeneous strategy use.

GitHub repository
